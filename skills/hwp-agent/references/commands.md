# Command reference

Every `hwp-agent` command and its options. Read the row for the command you are about to run.

| command | purpose |
|---|---|
| `hwp-agent convert IN.hwp OUT.hwpx` | HWP → HWPX (needs the jar) |
| `hwp-agent classify FILE.hwpx` | structured / weak / flat |
| `hwp-agent styles FILE.hwpx [--json]` | machine style roles (role → style id) |
| `hwp-agent check FILE.hwpx [--json]` | check the style system: ladder gaps, font-hierarchy violations, un-mapped bullet/structural styles, **stale `<hp:linesegarray>`**, and **insertion-marker placement** (which 구역 each `{{intro}}`/`{{body}}`/`{{references}}`… sits in; warns on a duplicate = ambiguous for write/build), and **package integrity** — header id lists out of order (an entry inserted mid-list shifts every later `charPrIDRef`, e.g. text rendering at a neighbour's 7pt), duplicate ids, `itemCnt` mismatch, references to undefined ids, and sections with no `<hp:secPr>` (zero-size page → runaway pagination). **Run it after any hand edit of a package's XML**; never insert header entries mid-list — append with the next free id (`doctor` = alias) |
| `hwp-agent normalize FILE.hwpx [-o OUT] [--dry-run] [--drop-linesegarray] [--json]` | declare `AI:HEADING_n`/`AI:BULLET_n` on a flat template's number/bullet styles (never in-place; default `<input>.normalized.hwpx`). `--drop-linesegarray` clears stale line-layout caches so Hangul recomputes them (fixes lines piled onto one — issue #15) |
| `hwp-agent fit tails FILE.hwpx [-o OUT] [--max-chars 4] [--min-spacing -5] [--min-ratio 95] [--dry-run] [--json]` | shorten paragraph widow tail lines by slightly reducing spacing/ratio (widow-tail fitting — issues #39, #61). Layout engine, in order: the document's own Hangul-saved linesegarray (fits verified with rhwp when available) → if any paragraph lacks one (e.g. a `write` output), re-save as HWPX through the hwp2pdf server and judge on Hangul's layout (skipped while Hangul runs on that machine or its queue is busy; paragraphs Hangul saved without a layout — it may lay out only the first pages — are judged with rhwp, and the report shows the split like `문단 한글 22 · rhwp 57`; if some stay unjudged it says `일부만 판정` and `--json` has `"partial": true` plus `paragraphs` counts — relay that as partial, not as "no tails") → rhwp's own layout (may differ from Hangul) → none: prints `판정 엔진 없음` with each engine's reason and **exits 3**. hwp2pdf comes from `~/.config/hwp-agent/hwp2pdf.json` (`server_url` + `token_file`) or, unconfigured, a `hwp2pdf serve` on this PC (`127.0.0.1:17650`); setup per situation is in README "Layout engines". When the user hits 판정 엔진 없음, relay the reasons and that section rather than guessing (exit 0 = judged, even with 0 candidates). The report names the engine used. `write`/`build --fit-tails` only warn when no engine is available. Stale linesegarray removed from modified paragraphs |
| `hwp-agent instructions FILE.hwpx [--json]` | AI:INSTRUCTION directions + `{{slots}}` |
| `hwp-agent extract FILE.hwpx [--body-only] [-o OUT.md]` | extract HWPX as body-focused Markdown; merged cells flattened (Excel-style) |
| `hwp-agent form analyze FILE.hwpx [--json]` | list fillable slots (label -> *empty* neighbour only) |
| `hwp-agent form analyze FILE.hwpx --grid [--json]` | list every table cell with its `cell:<t>:<r>:<c>` fill path — use when the cell you want already has text |
| `hwp-agent form fill FILE.hwpx --set K=V [-o OUT]` | fill slots by name |
| `hwp-agent form fill FILE.hwpx [--delete-rows cell:T:S-E] [--append-rows cell:T:+N] [--repeat-group cell:T:S-E:+N] --set ...` | restructure table rows first (delete → append/repeat → set), cell formats kept (issue #43) |
| `hwp-agent write C.md --template FILE.hwpx [--chapter N] [--table-template CAPTION] [--equal-columns] [--meta META.json] [--author NAME] [-o OUT]` | write Markdown into a template (`author` = alias). Generated tables size columns by content by default; `--equal-columns` keeps them equal. `--meta`/front matter fills the 표지·판권 slots; sets the document title/creator (see `references/cover-meta.md`) |
| `hwp-agent build MANIFEST.json [--meta META.json] [--author NAME] [-o OUT]` | assemble a multi-section report — a JSON manifest maps markers (`summary`/`intro`/`body`/`references`) to Markdown file(s) (a list is concatenated); each part fills its `{{marker}}` in its own section. On forms whose odd-page side wing (쪽날개) is baked into the master-page background picture (JI 과제 forms), each chapter's odd pages get that chapter's HEADING_1 title as a vertical text wing; `"chapter_header": false` in the manifest turns this off. Then fills the 표지·판권 slots from `"meta"` / `--meta` / front matter (see `references/cover-meta.md`) |
| `hwp-agent image list FILE.hwpx [--json]` | list figure image slots (ref, format, px size, caption) |
| `hwp-agent image replace FILE.hwpx IMG --ref image7 [--fit aspect\|none] [-o OUT]` | swap one figure image in place (`--caption "[그림 …]"` also targets it) |
| `hwp-agent meta FILE.hwpx [--set K=V]` | read/set document metadata |
| `hwp-agent verify FILE --bands [--json]` | deterministic section-band check (no vision/API key): groups pages by recurring 쪽날개 background image to reveal 표지·목차·본문·참고문헌 boundaries — catches content landing in the wrong section (issue #10). Facing-page mirrors merge; a page with no distinguishing background shows `—` |
| `hwp-agent pdf FILE [-o OUT] [--engine E]` · `hwp-agent docx FILE` | render to PDF/DOCX (`verify` on .hwp/.hwpx uses the same engines). `auto` order: `hwp2pdf-cli` (Hancom on this Windows PC) → hwp2pdf server → rhwp (PDF only). A Hancom engine is skipped while Hangul is open on its machine — never ask the user to close Hangul for it. The output line names the engine (`via hwp2pdf-cli · 한컴 · 이 PC` / `via hwp2pdf · 한컴 · 변환 서버` / `via rhwp · 근사 레이아웃`) and `note:` says why a preferred one was skipped; tell the user when the result is rhwp (pagination/spacing approximate; the CLI prints `참고: rhwp 근사 렌더(미리보기용)`). rhwp missing → `hwp-agent setup` downloads it. `--engine hwp2pdf` = Hancom only (fails rather than fall back to rhwp); also `local`/`remote`/`rhwp`, or `$HWP_AGENT_RENDER_ENGINE` |

`-o/--output` writes to a new file; omit it to edit in place. Point at a jar
elsewhere with `--jar` or `$HWP2HWPX_JAR`.
